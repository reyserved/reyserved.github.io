About the project

Blacktop Concepts had a large library of paving photos. I built a gallery that pairs selected photos with the city, project type, and scope so visitors can find work that looks like their own.

01

Challenge

The old gallery took a lot of scrolling. Someone comparing driveway contractors needed a faster way to find a local example, see what the job involved, and ask for an estimate. The rebuild also needed to stay easy for the client to update in Beaver Builder.

The brief
  • Audience

    Homeowners, property managers, and commercial property owners in Minnesota and Wisconsin.

  • Goal

    Help visitors find relevant local work and request an estimate.

  • Constraint

    Organize a large photo library within the existing Beaver Builder workflow.

02

Execution

  1. 01

    Gallery hero

    A direct H1 and a short intro give visitors two options right away. They can browse projects or request an estimate.

  2. 02

    Project jump links

    Anchor links take visitors to driveway replacement, new asphalt, parking lots, and before-and-after examples.

  3. 03

    Featured projects

    Each card shows the project type, city, scope, materials, and a link to request an estimate.

  4. 04

    Projects grouped by job type

    Dedicated sections help visitors find replacements, new paving, or commercial work.

  5. 05

    Expandable photo library

    The Show More grid keeps the full archive accessible and lets the client manage photos in Beaver Builder.

  6. 06

    Service-area links

    Internal links connect the gallery to local service-area pages for visitors exploring where Blacktop works.

03

Page architecture

  • HeroGallery overview with links to browse or request an estimate.
  • Project jump linksOn-page anchors for the main project types.
  • Featured workFour projects with location and scope.
  • Driveway replacementResidential driveway replacements.
  • New asphaltNew paving and overlay examples.
  • Before and afterVerified comparisons of the same project.
  • CommercialParking lots and larger commercial jobs.
  • Photo libraryFull archive under the Show More control.
  • Service areasInternal links to local pages.
  • Estimate CTARequest a paving estimate.
04

Outcome

  • Visitors can jump to the type of paving they need.
  • City and scope details make it easier to compare projects with similar work nearby.
  • The client can add future photos in Beaver Builder.
